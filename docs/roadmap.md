# Roadmap

## Fase 1: Base inicial

- Crear repositorio.
- Crear documentacion.
- Crear backend con FastAPI.
- Crear generadores iniciales para Word, PowerPoint y Excel.
- Crear interfaz web simple.

## Fase 2: Experiencia de usuario

- Mejorar interfaz visual.
- Agregar tarjetas de ideas.
- Agregar selector de estilo.
- Agregar modo Word, PowerPoint, Excel y automatico.
- Agregar boton de mejorar resultado.

## Fase 3: Archivos existentes

- Subir archivos Word.
- Subir archivos Excel.
- Subir archivos PowerPoint.
- Leer contenido.
- Corregir, mejorar o transformar archivos.

## Fase 4: IA avanzada

- Conectar proveedor de IA.
- Crear router de intencion.
- Crear agentes especializados.
- Agregar validacion de calidad.
- Agregar soporte para citas y referencias.

## Fase 5: Producto completo

- Login de usuarios.
- Historial de archivos.
- Plantillas profesionales.
- Exportacion a PDF.
- Modo estudiante, negocio y oficina.
