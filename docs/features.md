# Funciones planeadas

## Word

- Crear documentos desde cero.
- Corregir ortografia y redaccion.
- Mejorar estructura y estilo.
- Crear informes, ensayos, cartas y reportes.
- Agregar portada, indice, introduccion, desarrollo y conclusion.
- Preparar documentos academicos.
- Soporte futuro para APA 7.

## PowerPoint

- Crear presentaciones desde un tema.
- Generar diapositivas para exposiciones.
- Crear guion para presentar.
- Crear presentaciones de negocio.
- Redisenar presentaciones existentes.
- Convertir documentos en diapositivas.

## Excel

- Crear tablas automaticas.
- Crear formulas.
- Crear graficos.
- Controlar ventas, gastos e inventarios.
- Crear presupuestos.
- Crear dashboards basicos.
- Analizar datos.

## Modo automatico

El usuario escribe una idea o sube un archivo y la IA propone acciones como corregir, resumir, convertir, mejorar, redisenar o crear un archivo nuevo.
