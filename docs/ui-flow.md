# Flujo de interfaz

## Pantalla principal

Mensaje central:

**Que quieres crear o mejorar hoy?**

Opciones:

- Crear archivo nuevo.
- Mejorar archivo existente.
- Corregir texto o documento.
- Crear presentacion.
- Crear informe.
- Crear Excel automatico.
- Convertir archivo.
- No se, dame ideas.

## Selector

El usuario puede elegir:

- Word
- PowerPoint
- Excel
- Automatico
